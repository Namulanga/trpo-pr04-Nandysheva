# Практическая работа №4. PHP: формы и запросы
## Описание проекта
Веб-приложение для просмотра списка сотрудников и обработки заявок с использованием PHP.

Проект демонстрирует работу с CSV-файлами, обработку GET- и POST-запросов, проверку пользовательского ввода и безопасный вывод данных на HTML-страницу.

## Используемые технологии
- PHP
- HTML5
- CSS3
- CSV
- GET- и POST-запросы

### Назначение файлов
- `public/index.php` — главная страница приложения, отображение сотрудников, формы и обработка запросов.
- `src/functions.php` — вспомогательные функции для загрузки, обработки и проверки данных.
- `data/employees.csv` — файл с информацией о сотрудниках.
- `README.md` — описание проекта и инструкция по запуску.
## Реализованные возможности

### 1. Работа с CSV
Данные сотрудников загружаются из файла `data/employees.csv`.

Для обработки данных используются функции:
- `loadEmployees()` — загрузка списка сотрудников.
- `normalizeEmployee()` — нормализация данных сотрудника.
- `departmentsOf()` — получение списка отделов.

### 2. Отображение сотрудников
На главной странице выводятся:
- список сотрудников;
- количество сотрудников;
- количество отделов;
- средний стаж работы.

### 3. Фильтрация сотрудников
Реализована фильтрация списка сотрудников по отделу с помощью GET-запроса.

### 4. Обработка заявок
Форма позволяет отправить заявку с указанием:
- имени;
- электронной почты;
- отдела;
- стажа работы.

Для проверки введённых данных используется функция `validateInput()`.

### 5. Валидация данных
При отправке формы проверяются:
- наличие имени;
- длина имени — от 2 до 60 символов;
- корректность адреса электронной почты;
- принадлежность отдела к списку допустимых;
- стаж — целое число от 0 до 50.

При обнаружении ошибок пользователь получает сообщения об ошибках, а ранее введённые значения сохраняются в полях формы.
При успешной проверке отображается сообщение о принятии заявки.

### 6. Безопасность
Для безопасного вывода пользовательских данных используется функция `e()`, которая экранирует HTML-спецсимволы.
Это предотвращает выполнение введённого пользователем HTML-кода.

## Требования для запуска
Для работы проекта необходимы:
- PHP 8.0 или новее;
- расширение `mbstring`;
- веб-браузер.

## Запуск проекта
1. Скачайте или склонируйте репозиторий.
2. Откройте терминал в корневой папке проекта.
3. Проверьте наличие PHP:

```bash
php -v
```

4. Убедитесь, что расширение `mbstring` включено:
```bash
php -m
```

5. Запустите встроенный PHP-сервер:
```bash
php -S localhost:8000 -t public
```

6. Откройте в браузере адрес:
```text
http://localhost:8000
```
